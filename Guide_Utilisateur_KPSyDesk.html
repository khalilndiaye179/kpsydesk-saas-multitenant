Manuel de Formation KPSyDesk

Guide pas-à-pas pour les débutants - Apprenez à gérer votre matériel simplement
À qui s'adresse ce guide ? Ce document a été rédigé spécialement pour les personnes n'ayant pas de compétences techniques particulières en informatique. Nous allons vous expliquer, pas à pas et avec des mots simples, comment utiliser le logiciel KPSyDesk au quotidien.

1. Introduction : Comprendre KPSyDesk

Qu'est-ce que KPSyDesk ?
C'est un logiciel qui sert de carnet d'adresses géant pour tout le matériel informatique de votre entreprise (ordinateurs, imprimantes, téléphones). Au lieu de tout noter sur un cahier ou un fichier Excel compliqué, KPSyDesk classe tout automatiquement.

La sécurité avant tout (Le mode Hors-Ligne)
Contrairement à Facebook ou Google, KPSyDesk n'utilise pas Internet pour fonctionner. Toutes les informations que vous tapez restent enfermées dans votre propre ordinateur. C'est ce qu'on appelle le stockage "Local". Cela signifie qu'aucun pirate ne peut voler vos données via Internet. L'inconvénient ? Si votre ordinateur brûle, vos données sont perdues. D'où l'importance capitale de faire des Sauvegardes (expliquées à la fin du guide).

2. L'Accueil : Le Tableau de Bord

Dès que vous ouvrez KPSyDesk, vous arrivez sur l'écran d'accueil, qu'on appelle le Tableau de bord. C'est le résumé visuel de l'état de santé de votre entreprise.

Figure 1 : Votre écran de contrôle (Tableau de bord).

Comment lire cet écran ?

  • Total des Équipements : Le nombre total d'appareils enregistrés dans le logiciel.
  • Actifs : Le nombre d'appareils qui fonctionnent bien actuellement.
  • En Panne : Le nombre d'appareils cassés ou inutilisables qui attendent d'être réparés.
  • Les Graphiques : Les cercles colorés (les "camemberts") vous permettent de voir en un coup d'œil si vous avez plus de téléphones que d'ordinateurs, ou dans quels bureaux se trouvent vos machines.
  • L'Activité Récente : Une liste en bas de l'écran qui agit comme un historique (ex: "Julien a ajouté un nouvel ordinateur hier à 14h").

3. Le Cœur du Logiciel : La Gestion du Matériel

C'est ici que vous passerez le plus clair de votre temps. Cliquez sur "Inventaire" dans le menu sur le côté gauche pour y accéder.

Figure 2 : La liste complète de tout votre matériel.

A. Comment ajouter un nouvel appareil ?

  1. Cliquez sur le gros bouton + Ajouter un Actif en haut à droite.
  2. Une fenêtre s'ouvre. Remplissez les cases comme si vous remplissiez un formulaire d'inscription :
    • Nom de l'actif : Donnez-lui un nom facile (ex: PC Portable Marie).
    • Catégorie : Est-ce un ordinateur ? Un serveur ? Une imprimante ? Choisissez dans la liste.
    • Statut : S'il est neuf et fonctionne, choisissez En Stock ou Actif. S'il est cassé, choisissez En Panne.
    • Affectation : À qui appartient cet appareil ? (ex: Département RH, ou le nom de l'employé).
    • Prix d'achat : (Optionnel) Combien a-t-il coûté ? Utile pour la comptabilité.
  3. Cliquez sur Enregistrer en bas de la fenêtre. C'est fait !

B. Comment modifier ou effacer un appareil ?

Dans la liste de vos appareils, regardez tout à droite de la ligne d'un appareil : vous y verrez deux petits boutons.

  • Le bouton "Crayon" (Modifier) : Cliquez dessus si vous avez fait une erreur (ex: le prix était faux) ou si l'appareil a changé de propriétaire. Modifiez les informations et sauvegardez.
  • Le bouton "Corbeille" (Supprimer) : Cliquez ici uniquement si vous voulez effacer définitivement l'appareil de la mémoire du logiciel (par exemple, s'il a été vendu ou jeté).

C. Imprimer des étiquettes

Pour vous aider à vous y retrouver dans le monde réel, vous pouvez coller des étiquettes sur vos ordinateurs. Cliquez sur le bouton Générer Étiquettes (PDF). Le logiciel va créer un document PDF prêt à être imprimé avec le nom et les numéros de tous vos appareils.

4. Demandes d'Aide : Le Helpdesk (Tickets)

Le Helpdesk (qui signifie "Bureau d'aide" en anglais) est l'endroit où vous gérez les pannes signalées par les employés.

Figure 3 : Le centre de réparation et d'aide (Helpdesk).

Qu'est-ce qu'un "Ticket" ?

Un ticket, c'est simplement un petit message qui dit "Au secours, j'ai un problème". Par exemple : "L'imprimante du 2ème étage n'a plus d'encre". Au lieu de vous le dire à l'oral et que vous l'oubliiez, on crée un "Ticket".

Comment gérer un Ticket ?

  1. Cliquez sur + Nouveau Ticket.
  2. Sujet : Écrivez le problème courtement (ex: Plus d'encre imprimante).
  3. Demandeur : Qui a signalé le problème ? (ex: Fatou, de la comptabilité).
  4. Priorité : Est-ce Basse (pas pressé), Normale, ou Urgente (ça bloque le travail) ?
  5. Statut : Par défaut, c'est "Nouveau". Quand vous commencez à le réparer, changez-le en "En cours". Quand c'est réparé, mettez "Résolu".

5. Gestion des Employés (Utilisateurs & RH)

Allez dans le menu "Utilisateurs & RH". C'est ici que vous enregistrez les personnes qui travaillent dans l'entreprise.

L'Onboarding (L'arrivée d'un nouvel employé)

Le mot anglais "Onboarding" désigne l'accueil d'un nouvel employé. Quand un nouveau collègue arrive, vous devez lui donner un ordinateur, une chaise, un badge, etc.

  • Cliquez sur l'onglet Processus RH en haut de la page.
  • Sélectionnez un employé dans la liste.
  • Vous verrez apparaître une liste de cases à cocher (Checklist). Vous n'avez plus qu'à cocher "Ordinateur fourni", "Badge d'accès donné", etc., pour être sûr de n'avoir rien oublié !

6. Le Cahier de Procédures : Base de Connaissances (Wiki)

Le menu Base de Connaissances fonctionne comme un grand cahier de recettes pour votre entreprise.

Au lieu de réexpliquer 100 fois comment changer le toner de l'imprimante ou comment configurer le Wi-Fi, vous écrivez un Article ici une seule fois.

  1. Cliquez sur + Rédiger un Article.
  2. Donnez-lui un titre (ex: Comment changer l'encre de l'imprimante HP).
  3. Écrivez votre explication.
  4. Enregistrez. Désormais, tout le monde pourra venir lire cette "recette" au lieu de vous déranger !

7. L'Étape la plus IMPORTANTE : Sauvegarde et Restauration

ATTENTION DANGER : Comme expliqué au début, KPSyDesk ne stocke rien sur Internet. Si votre ordinateur tombe en panne, s'il est volé, ou si vous videz l'historique (cache) de votre navigateur Internet, TOUTES VOS DONNÉES SERONT EFFACÉES DÉFINITIVEMENT.
La seule solution est de faire une "Sauvegarde" toutes les semaines.

Comment Sauvegarder (Faire un double de sécurité) :

  1. Allez dans le menu Paramètres & Export.
  2. Cherchez le gros bouton bleu Exporter Base de Données (.json) et cliquez dessus.
  3. Un petit fichier (terminant par .json) va se télécharger sur votre ordinateur (souvent dans le dossier "Téléchargements").
  4. TRÈS IMPORTANT : Copiez ce petit fichier sur une Clé USB, envoyez-le vous par email, ou mettez-le sur votre Google Drive. L'essentiel est de le mettre en sécurité à l'extérieur de votre ordinateur !

Comment Restaurer (Réparer en cas de problème) :

Si un jour votre ordinateur casse, vous rachetez un nouvel ordinateur, vous copiez le dossier KPSyDesk dessus. Il sera totalement vide au début. Pas de panique !

  1. Allez dans le menu Paramètres & Export.
  2. Dans la section "Restauration", cliquez sur le bouton pour choisir un fichier.
  3. Allez chercher le fameux fichier .json que vous aviez mis de côté sur votre clé USB.
  4. Cliquez sur Restaurer les données. Comme par magie, tout votre inventaire réapparaîtra exactement comme il était le jour de la sauvegarde !

8. Gestion de la Licence

Figure 4 : Clé cryptographique pour l'activation.

Le logiciel est protégé. À la première ouverture, vous bénéficiez de 7 jours d'essai gratuit. Un bandeau orange en haut de l'écran vous rappelle combien de jours il vous reste.

Comment activer le logiciel ?

  1. Cliquez sur le bouton Activer la licence dans le bandeau orange en haut.
  2. Une fenêtre noire va s'ouvrir.
  3. Prenez la clé (le code secret) fournie par l'administrateur (ex: D3R4-P29X-B87A-YSPK).
  4. Tapez cette clé dans la case prévue et validez. Le logiciel sera débloqué pour une durée de 1 an.

Note : Pour vérifier si votre licence est active, allez dans le menu "À propos de l'application". Vous y verrez le statut (Activé ou Expiré) et le nombre de jours restants.
